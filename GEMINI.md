# BUNKER-disco — Правила разработки и стандарты контента

## 1. Полнота переноса карт из официальных изданий
- При проектировании и наполнении базы данных карточек проекта **BUNKER-disco** обязательно переносить и адаптировать **все карты** из:
  1. Базовой игры «Бункер» (версии 3.0 / 3.1);
  2. Официальных дополнений и самостоятельных изданий, включая «Бункер: Поколение Альфа» (Суперсилы, Фобии, Характер, обновлённые Багаж/Хобби/Факты), «Бункер-Б» и другие.
- Карточки не должны быть абстрактными заглушками: каждая карта адаптируется под двухфазный цикл PC-версии (Отбор у входа + 30 дней Выживания внутри).

## 2. Стандарты тегирования карт
Каждая карточка обязана иметь явный тег происхождения:
- `[BASE]` — карта из классической базовой игры «Бункер»;
- `[ALPHA]` — карта из издания / дополнения «Бункер: Поколение Альфа»;
- `[EXPANSION]` — карта из других официальных дополнений;
- `[NEW]` — авторская карта, созданная специально для PC-версии BUNKER-disco.

## 3. Конфигурируемость колод в настройках лобби
- Нестандартные и фантастические механики (в первую очередь колода **«Суперсила»** из «Поколения Альфа») **всегда должны иметь тумблер включения/отключения в настройках комнаты**:
  - `enableSuperpowers` (boolean, по умолчанию `false` для классического реалистичного режима, либо `true` для пати-режима);
  - `enablePhobias` (boolean, включение колоды фобий);
  - `enableCharacter` (boolean, включение колоды психологических черт характера).
- API, воркер и UI обязаны корректно обрабатывать генерацию раздачи как с включенными, так и с отключенными колодами дополнений.
