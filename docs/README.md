# 🏚️ BUNKER-disco

> **BUNKER-disco** — это PC-версия настольной игры «Бункер» в стиле Jackbox: один большой ТВ-экран для всех с кинематографичной 3D-воксельной сценой и личный веб-интерфейс у каждого игрока на телефоне или ПК. Человечество на грани гибели. Только половина выживших попадёт в спасительное убежище. Игра масштабируется от **4 до 20 игроков**, работает прямо в браузере без установки и сочетает социальную дедукцию, ролевые споры, активные способности и пошаговое выживание на 30 дней.

---

## 🎮 Концепция

BUNKER-disco построен по **Jackbox-модели**: хост открывает игру на большом ТВ/мониторе, а игроки моментально подключаются со смартфонов по 4-5-значному коду. Роль ведущего **ВСЕГДА берёт на себя сам ПК** (автоматический ИИ-гейммастер со звуковыми эффектами, контролем таймингов дебатов и драматическими анимациями изгнания).

Геймплей разделён на **две фазы**:

| Фаза | Название | Визуал на ТВ-экране (Three.js) | Суть |
|------|----------|---------------------------------|------|
| 1️⃣ | **Отбор** | Постапокалиптический хвойный лес, костёр, тяжелая гермодверь убежища; бункер внизу скрыт **туманом войны (Fog of War)**. При раскрытии карт бункера сквозь туман проявляются 3D-комнаты. | Игроки раскрывают карточки, торгуются, тратят ОД, активируют способности профессий и суперсилы, убеждая группу в своей незаменимости. В конце каждого раунда изгоняется один игрок. |
| 2️⃣ | **Выживание** | Гермодверь запечатывается. Выжившие спускаются внутрь бункера: воксельные фигурки ходят по комнатам, работают за станками, готовят, чинят дефекты, тушат пожары и спят. | 30 игровых дней: распределение ролей, управление ресурсами (Еда, Вода, Воздух, Медикаменты, Энергия, Мораль), устранение внутренних угроз и саботажа. |

**Официальное правило вместимости:**
Вместимость бункера рассчитывается строго по правилам «Бункера» как ровно половина от числа участников в меньшую сторону:
$$K = \lfloor N / 2 \rfloor$$
*(например: 4 игрока → 2 места, 7 игроков → 3 места, 10 игроков → 5 мест, 20 игроков → 10 мест)*.

## 🚀 Быстрый старт

### Вариант 1: Запуск через Docker Compose (Рекомендуемый)

Развёртывание всего стека (Frontend, API, Worker, Redis, MongoDB) в одну команду:

```bash
# Клонировать репозиторий и запустить контейнеры
docker compose up -d

# Открыть экран хоста (для вывода на ТВ/проектор)
http://localhost:3000

# Игроки подключаются с телефонов по локальному IP или домену
http://<YOUR_IP>:3000
```

Подробное руководство по инфраструктуре и .env: [`docs/deployment/docker.md`](deployment/docker.md).

### Вариант 2: Запуск в режиме разработки

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Открыть в браузере
http://localhost:3000
```

1. Нажмите **«Создать комнату»**
2. На экране появится **код комнаты** и QR-код
3. Поделитесь кодом с игроками (до 20 человек)

### Подключение игрока (телефон / планшет / ПК)

1. Откройте мобильный браузер и введите адрес игры
2. Введите **код комнаты** и имя персонажа
3. Карточки персонажа раздаются автоматически в закрытом виде на экран смартфона

## 🛠️ Технический стек

| Слой | Технология | Роль |
|------|-----------|------|
| **Frontend** | Vue.js 3 + Pinia | SPA контроллера игрока и экрана ТВ |
| **3D Визуал** | Three.js (Voxel Engine) | Воксельная сцена (лес, гермодверь, бункер с туманом войны) |
| **UI-стиль** | Пиксельный RPG / Retro CRT | Драматический интерфейс на ТВ и минималистичный на смартфонах |
| **Backend API** | Node.js (Fastify/Express) | REST API управления комнатами, сценариями и таймлайном |
| **Worker** | Node.js Worker Thread / BullMQ | Асинхронный процессинг действий игроков и суточных тиков |
| **Real-time** | WebSocket (Socket.io) | Двусторонняя синхронизация ТВ-экрана и смартфонов |
| **База данных** | MongoDB | Хранение профилей, колод карт, готовых сценариев |
| **Кэш / Очереди** | Redis 7 | Состояние комнат in-memory, очереди действий, pub/sub |
| **Деплой** | Docker & Docker Compose | Контейнеризация и запуск в 1 команду |

## ⚡ Ключевые механики

- 🤖 **Автоматический ПК-гейммастер** — система сама ведет регламент, озвучивает фазы и исключает предвзятость ведущего.
- 📐 **Официальная формула вместимости $\lfloor N / 2 \rfloor$** — ровно половина участников спасается (масштабирование до 20 игроков).
- 🌲 **3D Воксельная сцена с туманом войны** — лес снаружи, таинственный бункер внизу с динамическим открытием комнат.
- 🎬 **Режиссёрская камера (Camera Director)** — зумы на выступающих игроках, панорамы при голосовании, драматические изгнания.
- 🃏 **Вайб коллекционных карточек (TCG)** — тактильный дизайн карт в стиле ламинированных пропусков убежища, физические блики гироскопом, бронированные рубашки с замками `[LOCKED]` и 3D-перевороты при открытии.
- 🔄 **Гибкий перерандом персонажа (Маллиган)** — настраиваемый лимит перерандома в лобби (`rerollLimit` от 0 до 999), дающий шанс сбросить неудачную руку перед стартом дебатов.
- 📅 **Редактор сценариев и таймлайна (Scenario Builder)** — возможность детально настроить цепочку катастроф и угроз на 30 дней.
- ⚡ **Активные способности и суперсилы** — профессии с ОД/кулдаунами и опциональный пати-тумблер суперсил.
- 🎒 **Инвентарь, обмен, кража, крафт** — предметы решают исход выживания.
- 🎯 **Скрытые квесты и саботажники** — предатели внутри бункера и альтернативные условия победы.
- 📺 **Jackbox-стиль** — смартфон как геймпад, ТВ как общая арена.
